## Lernziele

- [x] den Zweck der Datenmodellierung im Gesamtprozess der Datenbankentwicklung erklären
- [x] die Begriffe **Entität**, **Entitätsmenge** und **Attribut** definieren und an eigenen Beispielen anwenden
- [x] die vier Schritte von der Anforderung bis zur fertigen Datenbank benennen und deren Zweck erklären
- [x] mittels Substantiv-Analyse aus einer Anforderungsbeschreibung Kandidaten für Entitätsmengen ableiten
- [x] entscheiden, ob ein Sachverhalt als eigene Entitätsmenge oder als Attribut modelliert werden sollte
- [x] Konstruktionselemente eines Konzeptionelles Datenmodell sind bekannt.
- [x] Konzeptionelles Datenmodell erstellen und fehlende Informationen ermitteln bzw. Redundanzen klären.
